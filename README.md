# 1D Heat Conduction Simulation — SigmaCamp Workshop

This repository contains a Python simulation and visualization of **1-dimensional heat conduction in an aluminum rod**, created and taught as part of a **SigmaCamp 2025 workshop**.  
As a counselor, I led a hands-on experiment where campers heated one end of a real aluminum rod using a heating plate, measured temperature changes at several points, and then compared their data to this simulation written in Python.

The goal of the workshop was to help students understand how heat spreads through a material over time and how physical processes can be modeled mathematically.

---

## 1. Physical Model

The system models a uniform aluminum rod of length $L$ with one end heated and the other insulated.  
The temperature $T(x,t)$ satisfies the **1-dimensional heat equation**

$$
\frac{\partial T}{\partial t} = \alpha \frac{\partial^2 T}{\partial x^2},
$$

where $\alpha = 9.7\times10^{-5}\,\text{m}^2/\text{s}$ is the thermal diffusivity of aluminum.

### Boundary and Initial Conditions

$$
T(0,t) = T_{\text{hot}}, \qquad \frac{\partial T}{\partial x}(L,t) = 0, \qquad T(x,0) = T_0.
$$

Here $T_{\text{hot}}$ is the heating-plate temperature, and $T_0$ is the initial temperature of the rod.

The simulation and experiment both followed these physical assumptions.

---

## 2. Numerical Simulation

The program solves the heat equation using the **finite-difference method** with explicit time stepping.  
At each time step:

$$
T_i^{n+1} = T_i^n + \alpha \frac{\Delta t}{(\Delta x)^2} (T_{i+1}^n - 2T_i^n + T_{i-1}^n),
$$

where $\Delta x$ is the spatial step, $\Delta t$ the time step, and the stability condition is

$$
\Delta t \leq \frac{(\Delta x)^2}{2\alpha}.
$$

The temperature evolution is visualized in both **2D and 3D**, showing how heat gradually moves from the hot end through the rod.

## 7. Teaching Context and Learning Outcomes

I made this project for the **SigmaCamp 2025** workshop, where I taught campers about **heat conduction** using both an experiment and a Python simulation.

During the activity, campers heated one end of an aluminum rod and took temperature readings at a few points along it.  
They compared their results with my simulation of the 1D heat equation

$$
\frac{\partial T}{\partial t} = \alpha \frac{\partial^2 T}{\partial x^2}.
$$

The goal was to show how math can describe something you can actually see happening.  
Students learned how boundary conditions change what the graph looks like, how to read and plot data, and how computer code can model a real experiment.

For me, running this workshop helped me get better at explaining ideas in simple words and using Python to show physical processes step by step.

## 8. Future Work

There are a few things I’d like to add or improve later:

- Make $\alpha$ depend on temperature, so it changes as the rod heats up.  
- Add heat loss to the air, not just conduction through the rod.  
- Try a **2D version** for a metal plate instead of a rod.  
- Let users load their own data from experiments to compare it with the model.  
- Build a small **interface** where you can change values like $L$, $\alpha$, or $T_{\text{hot}}$ and instantly see what happens.  

These would make the simulation more realistic and useful for teaching.
